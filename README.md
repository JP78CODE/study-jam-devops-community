# Study Jam DevOps Community

Repository ini merupakan _community book_ untuk Study Jam Divisi DevOps, yang digunakan sebagai media praktik pada materi fundamental Git & GitHub. Peserta dapat berkontribusi dengan menambahkan profil singkat dalam format Markdown melalui workflow fork dan pull request.

## Tujuan

- Mendokumentasikan perkenalan anggota komunitas Study Jam DevOps.
- Berlatih workflow kolaborasi Git dan GitHub.
- Membiasakan kontribusi melalui branch dan Pull Request.
- Mempraktikkan review sebelum perubahan digabungkan ke repository utama.

## Cara Berkontribusi

1. Fork repository ini ke akun GitHub kamu.
2. Clone repository hasil fork ke komputer lokal.
3. Buat branch baru untuk kontribusimu.
4. Tambahkan satu file profil di folder `participants/`.
5. Pastikan nama file mengikuti aturan di `CONTRIBUTING.md`.
6. Commit perubahan dan push branch ke repository hasil fork.
7. Buat Pull Request menuju branch utama repository ini.
8. Tunggu review dan lakukan revisi jika diminta.

Baca [`CONTRIBUTING.md`](CONTRIBUTING.md) sebelum mengirimkan kontribusi.

## Struktur Repository

```text
study-jam-devops-community/
├── README.md
├── CONTRIBUTING.md
└── participants/
    └── nama.md
```

Folder `participants/` akan terisi seiring kontribusi anggota komunitas.

## Kebijakan Privasi

Repository ini bersifat publik. Cantumkan hanya informasi yang nyaman kamu bagikan secara publik. Jangan mencantumkan alamat rumah, nomor telepon pribadi, nomor identitas, kredensial, atau informasi sensitif lainnya.

## Maintenance

Repository ini dikelola oleh pengurus Divisi DevOps untuk keperluan Study Jam, khususnya praktik materi fundamental Git & GitHub. Pengurus Divisi DevOps memiliki keleluasaan untuk menyesuaikan struktur, isi, dan panduan repository sesuai kebutuhan pelaksanaan Study Jam.
